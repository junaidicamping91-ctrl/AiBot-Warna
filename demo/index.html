AimBot Warna — Robot Pembidik + Audio

SIMULASI · tanpa hardware

Simulator tanpa hardware dari alur poster «Implementasi Object Detection pada Robot Pembidik Sasaran»: Python/OpenCV + YOLO di PC → perintah serial ke Arduino → servo pan–tilt dengan PID. Versi ini mengganti deteksi objek dengan tebakan warna, lalu robot berbicara / memainkan nada sesuai warna yang terdeteksi.

MODE SIMULASI
SUMBER: SIMULASI FPS 30 SEARCHING DETEKSI: HSV

Cara pakai: klik kartu warna di kanan untuk mengganti target → kotak HUD membidik → servo PAN/TILT mengikuti → nada/ucapan diputar setelah kamu menekan Aktifkan Suara.
